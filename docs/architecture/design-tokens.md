# نظام التوكنز — سُرى

> المصدر الوحيد للحقيقة هو كتلة `:root` في أعلى `style.css`. هذا الملف يشرح
> *لماذا*، ويقول ماذا تفعل عندما لا تجد التوكن الذي تحتاجه.

## القاعدة

أي قيمة في `style.css` يجب أن تكون **مرجعًا** لتوكن، لا رقمًا حرفيًا. اللون
والمسافة ونصف القطر والمدة ومنحنى الحركة وطبقة `z` — كلها تأتي من `:root`.

عندما لا يوجد توكن مناسب، الحل الصحيح دائمًا تقريبًا هو **توسيع سلّم قائم**،
لا كتابة قيمة جديدة في مكان الاستخدام. القيم المتناثرة هي بالضبط ما يجعل
الموقع يُقرأ كشيء مُولّد آليًا بدل شيء مُصمَّم.

## السلالم

| المجموعة | التوكنز | ملاحظة |
|---|---|---|
| ذهب | `--gold-050 … --gold-900` | الهوية. `--gold-500` هو الذهب الأساسي |
| ذهب شفاف | `--gold-rgb`، `--gold-a08 … --gold-a60` | للتوهج والحلقات فوق خلفية مجهولة |
| أسطح | `--surface-0 … --surface-4` | ٠ الأعمق، ٤ الأكثر ارتفاعًا |
| حبر | `--ink-0 … --ink-4`، `--ink-inverse` | نص، فاتح ← داكن |
| لوح الملاحة | `--plate-ink`، `--plate-ink-dim` | **لا ينقلب مع الثيم** — شريط الملاحة لوح أسود مطفأ في كل الأوضاع |
| دلالي | `--ok/-soft/-deep`، `--warn…`، `--err…`، `--info…` | معنى لا لون |
| حالة الحرف | `--state-correct/present/absent` (+`-edge`) | مفردات الألعاب، منفصلة عمدًا عن `--ok/--warn` |
| مسافة | `--sp-1 … --sp-12` | أساس 4px |
| نصف قطر | `--r-xs/sm/md/lg/xl/full` | |
| طباعة | `--fs-4xs … --fs-6xl`، `--fs-hero`، `--fs-display` | |
| إيزنغ | `--ease-expo/quart/back/soft` | `--ease-expo` هو منحنى البيت |
| مدة | `--dur-1 … --dur-6` | |
| ارتفاع | `--el-1 … --el-4` | |
| طبقات | `--z-loom/veil/content/nav/modal/fx` | المكان الوحيد الذي يخرج منه `z-index` |

## لماذا سلّم الخط مضغوط في أسفله

الحرف العربي يبدو بصريًا أصغر من اللاتيني عند نفس عدد البكسلات، فالفروق
الصغيرة في الأحجام الصغيرة **تُرى**. لذلك السلّم أدق بين `--fs-4xs` و`--fs-base`
مما هو معتاد في سلالم لاتينية.

## الوضع الفاتح

`html[data-theme="light"]` **يعيد توجيه السلالم نفسها** (`--surface-*`، `--ink-*`)
بدل أن يتجاوز قواعد فردية. هذا هو الوضع الفاتح كله تقريبًا. القواعد ذات
`!important` المتبقية تخص فقط النصوص التي تطفو مباشرة فوق الفيديو.

**الوضع الفاتح جاهز لكنه غير مُفعَّل**: `src/main.js` فيه `THEMES = ['dark']`،
ولا يوجد أصلًا زر ثيم في نافذة الإعدادات (`index.html` فيه `seg-control`
لحجم الخط وعائلته فقط). تفعيله = إضافة `'light'` إلى المصفوفة + إضافة
`seg-control` ثالث — قرار منتج، لا قرار تقني.

## ما لا يُلمَس

- `letter-spacing: normal !important` على العربية — التتبّع يكسر وصلات الحروف.
  الضبط الطباعي يتم بـ`line-height` و`word-spacing` و`font-size` فقط.
- ألوان الألعاب الخاصة (زليج، خيوط، ميداليات…) بقيت قيمًا حرفية داخل كتل
  قواعدها. طيّها في سلالم الهوية كان سيمحو تمييزًا مقصودًا بين الألعاب.

## أرقام الهجرة (٢٠٢٦-٠٧-٢٥)

| | قبل | بعد |
|---|---|---|
| مواضع hex | ٢٥٨ | ١٠٤ (كلها ألوان ألعاب خاصة) |
| hex مميّز خارج `:root` | ١٦١ | ٨٦ |
| أحجام خط حرفية بـrem | ٤٠ | **٠** |
| منحنيات bezier مكتوبة يدويًا | ٢٥ | ٠ |
| قيم `border-radius` حرفية | ١٠٦ | ٠ |
