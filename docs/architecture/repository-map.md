# Repository map

Where things live, and — more usefully — **where to go when you want to change
something**. If you read one file before touching this repo, read this one.

## The one fact that explains the layout

`scripts/build/dist.js` builds the deploy folder from an **explicit whitelist**.
It copies files it names, refuses nine file extensions, skips anything whose
name starts with `_`, and fails the build on a stray file it did not expect.

That single design decision is why this repository can hold design masters,
archives, audits, generators, and a film pipeline without any of it being one
mistake away from production. **A file not on the whitelist cannot ship, wherever
you put it.**

The corollary is the rule to remember: to change what ships, edit the whitelist.
Adding a file next to `index.html` does nothing.

```
public/       deployed assets only: brand/ navbar/ story/ tallal/ vendor/
supabase/     functions/ · migrations/ · sql/ · templates/ · config.toml
tests/        35 files, flat, node:test
scripts/      build/ · bank/ · assets/ · qa/ · promo/
docs/         architecture/ · operations/ · security/ · performance/ · product/ · historical/ · qa/
promo/        launch-film source (ad.html · ad.css · *.mjs)
prompts/      LLM prompt library
tools/        local dev server + one-off Python utilities
_design-src/  full-resolution masters — generator INPUTS, gitignored, never shipped
archive/      non-production material, gitignored except its README/MANIFESTs
```

**Nine paths are frozen at the root**: the nine HTML/JS/CSS files listed first.
Cloudflare Pages serves them from the deploy root, `scripts/build/csp.js` hashes
five pages' inline scripts by root-relative path, and `preflight.js` asserts
they exist. Moving `index.html` into `src/` is not a refactor, it is an outage.

## I want to change…

| …this | Go here | Then |
|---|---|---|
| Game logic, UI behaviour, anything the player sees | `src/` — **never `app.js`** | `npm run build` |
| A game's rules or difficulty curve | `src/games/<game>.js`, `src/core/progression.mjs` | `npm test` |
| Which games are live | the `LIVE_GAMES` array in `src/ui/meta.js` | that array is the source of truth, not the DOM; the tests reach it through `tests/helpers/live.js` |
| Puzzle content | `bank/*.json`, or the generators in `scripts/bank/` | `node scripts/bank/audit_banks.js` |
| Styling | `style.css` (shipped verbatim — comments included) | `npm run build` bumps the cache-bust |
| The 404 page | `src/tallal.js` → `tallal.js`, `404.html` | `npm run bundle:404` |
| What gets deployed | the whitelist in `scripts/build/dist.js` | `npm run dist` |
| CSP / security headers | `scripts/build/csp.js` — **not `_headers`** | `_headers` is generated |
| Cache-busting `?v=` | nothing — `scripts/build/preflight.js` derives it from a content hash | hand-edits are overwritten |
| Database schema | a **new** timestamped file in `supabase/migrations/` | apply by hand; see `supabase/sql/README.md` |
| An Edge Function | `supabase/functions/<name>/` — the source of record | deploy via CLI; never hot-edit in the dashboard |
| Auth email templates | `supabase/templates/` | paste into the Supabase dashboard |
| The Telegram bot | `bot.js` | `npm run bot` |
| The AI retrieval corpus | `AUTHOR_DOCS` in `bot.js` | it names doc paths — verify they resolve |
| Design plates / hero art | `_design-src/`, then a generator in `scripts/assets/` | regenerates the WebP under `public/` |
| The launch film | `promo/` | `npm run promo:render` |
| Docs | `docs/<category>/` | `docs/historical/` is a record — leave it factually intact |

## Where the build is

```bash
npm run build   # esbuild src/ → app.js + tallal.js, then preflight, then CSP
npm run dist    # build, then assemble dist/ from the whitelist
npm test        # 443 tests, 35 files
npm run lint    # node --check across 120 first-party JS/MJS files
npm run sweep   # 126 headless runs: 21 levels × 6 games
```

Deploy is `npm run dist` then `npx wrangler pages deploy dist --project-name sura`.
**Never `wrangler pages deploy .`** — that uploads `.env`.

## Two directories that are not what they look like

**`supabase/migrations/` vs `supabase/sql/`.** Both hold SQL; only the first is
an ordered ledger. `supabase/sql/` is hand-pasted scripts, including two files
marked *never run* and one that is an outright trap
(`allow_new_game_types.sql` — it would narrow a CHECK and break «أمثال»). Read
`supabase/sql/README.md` before executing anything from either.

**`public/` vs `_design-src/`.** `public/` holds only derived, deploy-sized
assets. The multi-megabyte originals they are generated from live in
`_design-src/` and are gitignored. A 2 MB PNG becomes a 25 KB WebP; only the
WebP is deployed.

## Things that look like bugs and are not

Documented so nobody "fixes" them a third time:

- **`letter-spacing: normal !important` on Arabic** — deliberate.
- **Never animate `opacity` in keyframes on `.scroll-section` descendants** —
  iOS Safari freezes the `from` frame. Use transforms.
- **`app.js` is `<script src>` with `rel="preload"` and deliberately not
  `defer`.**
- **`arNum` is `n => String(n)`** — Sura shows Western digits by design.
- **Empty state is «—», never «٠»** (`docs/architecture/identity.md`).
- **`copyDir("public/vendor")` copies an empty directory** — flagged, not
  "fixed"; it is a placeholder for vendored assets.

## What is deliberately not in git

`archive/`, `_design-src/`, `dist/`, `promo/.work/`, `app.js.map`, `.bench/`,
`.hero_work/`, `review_*.html`, and **`supabase/sql/seed.sql`** — the last
because it is regenerable from committed inputs *and* it is the plaintext answer
key to every seeded puzzle.

`archive/README.md` and `archive/*/MANIFEST.md` are force-tracked: the **record**
of what was archived and why is versioned, the bytes are not.
